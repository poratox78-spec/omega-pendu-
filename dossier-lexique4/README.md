## Configuration à indiquer (cheat-free, optimale)
L'app démarre **tous interrupteurs OFF**. La config optimale **cheat-free**
(A1 · A2 · A3 ÉTEINTS = aucun lookup lexical dans le choix d'une lettre) est
détaillée dans le rapport **§8.3** — ≈ 97,3 % cheat-free intégral (sans jamais
lire le mot caché) ; plafond oracle exclu 98,7 %.
