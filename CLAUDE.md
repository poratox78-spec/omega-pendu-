## Décisions clés (ne pas re-débattre)
- **Cible n°1 = dys / troubles de l'écrit.** **Cadre = phrases** (mots isolés = mal posés : 84 % ont des homophones).
- Pourquoi dictée : **phon→ortho = force mesurée** d'OMEGA ; **profil de défaite = signature dyslexie phon** (rapport §11.2 : 58 % voisée/sourde).

Détail : `dictee/JOURNAL.md`.
- **FALSIFIÉ — NE PAS REFAIRE** : (a) M3_d ne désambiguïse pas les homophones (aucune entrée sens/contexte) — `dictee/README.md` (§ « Falsifié M3_d ») ; (b) **pendu de phrases** comme levier winrate : le partage de lettres fuit les fins → la valeur est dans la *déclaration*, mesurée marginale sur le moteur ≥7 — `evo/PHRASE_HANGMAN_PROBE.md`. *Nuance* : le **readout bPC** de M3_d (cLetterScore) est « peut-être utile » (+3,4, cheat-free) — `AUDIT_OMEGA.md` §3 ; (c) **C cognitif OOV** (`AUDIT_OMEGA §1.8-1.12`) : la cognition seule fait ~11 % OOV ; le levier est l'**agrégation** = n-gram (§1.7) branché en **voie sublexicale arbitrée OS** (§1.9, bascule auto par fiabilité, in-lex ~97 %/OOV ~60 %) + **gap-aware** (§1.10, plus proche voisin révélé à distance 1..4, **+2 pts OOV** = 1er gain cognitif réel). **FALSIFIÉS — ne pas refaire** : lissage par substrat `letterVecsSDIM`, pooling position-relative, le **C *léger* appris** (maxent/GATE/POE, `evo/learned_c_probe.js`), ET le **C *lourd* (transformer)** — construit + mesuré (§1.12, sonde `evo/heavy_c_probe.js` ; winrate à config optimale `evo/heavy_c_winrate.js`, hook moteur `_neoHeavyCDist` OFF-inerte) : **parité** avec le gap-aware (OOV Δ −1,3, perd 2/3 graines), l'entraînement sur **vraies parties** (`evo/harvest_states.js`) **recule** (−14,6, couverture lexicale). **Ne PAS câbler.** Au-delà = SOTA-scale hors-ligne → arbitrage explicite requis (c'est là qu'IndexedDB des poids deviendrait justifié).
